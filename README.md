# Web Technology Lab Practice

A repository dedicated to storing all lab exercises, tasks, and code samples completed during the Web Technology course.

---

## 📂 Repository Contents

* **HTML & CSS:** Static layouts, responsive designs, and semantic form building.
* **JavaScript:** Client-side scripting, DOM manipulation, and interactive form validation.
* **PHP Fundamentals:** Server-side scripting, form handling (`$_POST`/`$_GET`), and session management.
* **PHP MVC:** Advanced lab tasks structured using the Model-View-Controller architecture.
* **MySQL:** Database design, table schemas, and executing CRUD operations.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (Procedural & MVC)
* **Database:** MySQL
* **Environment:** XAMPP (Apache & MySQL)
